# «Свой ориентир» — React-сайт

Адаптивная React-страница по предоставленному макету. Стили и декоративные изображения находятся локально в проекте.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который выведет Vite (обычно `http://localhost:5173`).

## Сборка

```bash
npm run build
npm run preview
```

## Что уже работает

- переходы по разделам через верхнее меню;
- карточки папок и тематические блоки открывают информационные окна;
- буквы глоссария переключают компактную панель-подсказку;
- кнопки записи открывают форму с демонстрационным подтверждением;
- карточка с play-иконкой открывает блок-заглушку для видео.

Форма записи пока работает локально и не отправляет заявки на сервер. Для реального приёма заявок нужно подключить API или сервис форм.
